# Getting Started

## Installation

```bash
conda env create -f environment.yml
conda activate cfdUQ
```

## Project Layout


## Step-by-Step Workflow
Each run is controlled by a YAML config file. 
The template of the files are in `Template`.

Copy the `Template` folder to your working directory (rename the folder as `files`)




### 1. Generate LHS Samples for input error

Modify the `files/input_error/template_input_error_config.yaml` for your own case. 

```bash
cd preprocessor/inputlhsGen
python processor_BEPU_sampling.py files/input_error/my_input_error_config.yaml

```
The processor generates the random samples using Latin-hypercube approach, run the following command:
The documentation could be found in [processor_BEPU_sampling.py](api/processor_BEPU_sampling.md).


### 2. Estimate numerical error using least-square approach 
Modify the `files/discretization_error/template_least_square_config.yaml` for your own case.

```bash
cd preprocessor/numericalleastSquare
python processor_leastSquare.py files/discretization_error/my_least_sqare_config.yaml
```
The processor: 
1. Reads the config file and find the csv files of the target quantitiy
2. Perform point-by-point least-square estimation based on the given csv files.

The documentation could be found in [processor_leastSquare.py](api/processor_leastSquare.md)


### 3. Run the UQ Driver
The UQ script will need following files

```
your_working_directory
├── config
│   └── my_uq_config.yaml 
├── discretization_error # Done in step 2
│   ├── my_least_square_config.yaml
│   ├── h1
│   │   └── ils.csv
│   ├── h2
│   │   └── ils.csv
│   ├── h3
│   │   └── ils.csv
│   ├── h4
│   │   └── ils.csv
│   └── ls  
│       ├── U_0
│       │   └── U.csv
│       ├── U_1
│       │   └── U.csv
│       ├── U_2
│       │   └── U.csv
│       └── U_3
│           └── U.csv
├── input_error  # Done in step 1
│   ├── BEPU_bot_lhs_samples.csv # <- Generated by step 1
│   └── my_input_error_config.yaml
├── java
│   └── my_java.java
├── model_error
│   └── ils.csv # correspond to the baseline.sim
├── sim
│   ├── basline.sim  
│   └── rf.csv # dummy file; no need to touch it 
└── slurm
    └── my_job_submission_script.slurm # control how starccm is called and ran

```

Once the files are ready, run: 
```bash
cd driver
python driver_uq.py
```


For each sample ID, the driver:
1. Creates a sample folder under `root/`
2. Copies the `.sim`, ILS, and Java files
3. Injects BEPU parameters into the Java macro
4. Generates a random field (GRF/KLE) remotely
5. Submits the job via SLURM (`EngagingManager`) or runs it locally (`LocalManager`)

The documentation can be found in [driver_uq.py](api/driver.md)
